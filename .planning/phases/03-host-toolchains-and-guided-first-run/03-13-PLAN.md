## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP server → `.part` file | a vendor or GitHub server (or a proxy in between) decides how many bytes arrive and when the connection ends |
| probe.json ← concurrent porter processes | two `setup --json` runs write the same cache file at once |
| porter fix text → the player's terminal | a command with the player's own folder names in it, meant to be pasted |

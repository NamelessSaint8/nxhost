- Edge PKG-07 (unclassified by the probe) is resolved by the truths above.
- D-05 says porter compares the pins with the restored `.nupkg.sha512` files, and that is what this plan does. RESEARCH A2 found that file holds the hash of the signed package, which changes if nuget.org re-signs it, while `project.assets.json`'s `sha512` (the content hash) does not; with `.nupkg.sha512` a re-sign stops every port, naming the package, until the pin is bumped. Using X (.nupkg.sha512) per the user's decision; research suggested Y (contentHash). Switching is one field in nuget.hashes and a regenerated NUGET block.
- RESEARCH A7: `dotnet restore` runs no package-supplied build targets, so the check runs before any package code; if that is wrong, the check still runs before nx_extract or the translator is built and run.
- Open Question 1: the cross-game tools lock is added (the research recommendation); HARD-04 itself is about one game folder.
- Moving restores to `<user dir>/nuget` means the first port after this update downloads about 50 MB of packages again and needs the network once (RESEARCH Runtime State Inventory); the release notes should say so.

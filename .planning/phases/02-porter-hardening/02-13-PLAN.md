The rule therefore requires every link's name and target to be plain printable ASCII and non-empty, refuses a target component that names a link only when compared case-insensitively (`str.casefold`), and refuses a link that shares its (casefolded) name with another member or has a member under it. All 58 real links pass. This is reversible: it can be loosened if a vendor ever ships a non-ASCII link.
- The step cap is 40 link substitutions per resolution (Linux's MAXSYMLINKS); a loop and a chain longer than that get the same refusal.

- Prohibition recall breadcrumbs (not minted): zip-slip and path traversal are canon security items, covered by the truths and T-02-36; "no toolchain committed" is enforced by arch_rules check 8.

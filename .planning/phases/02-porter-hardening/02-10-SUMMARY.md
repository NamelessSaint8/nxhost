# Phase 2 Plan 10: NuGet Content-Hash Pins, Shared Tools Lock and CONCERNS Closure Summary

**Every port now runs `dotnet restore` into `<user dir>/nuget` and checks each restored package's content hash (the `sha512` in `obj/project.assets.json`) against 58 generated `pins.NUGET` entries before nx_extract, the survey or the translator is built. Shared tool builds take a blocking `<user dir>/tools/.porter.lock`, and CONCERNS.md closes every concern row by row.**

## Accomplishments
- `porter/nuget.py`:
  - `hashes()` reads the packages and their folders from the assets file.
  - `check()` compares each package with `pins.NUGET`. It stops on a mismatch, an unpinned package or a missing hash, names the package and both values, and removes the package folder.
  - `restored()` takes the tools lock, then runs restore and check, then the caller's build.
- `pins.NUGET` was generated by `devtools/nuget_pins.py` from a real restore with .NET SDK 10.0.403. It holds 58 packages: LibHac/0.19.0 for nx_extract and 57 for dmsh_xlate. The LibHac pin starts `7uMUGFpO2V0`, so the content hash was read, not the signed-file hash.
- `porter/pipeline.py` has three call sites:
  - `extract()` builds nx_extract inside `nuget.restored()`.
  - `experimental_profile()` runs its survey inside it, because the survey builds nx_extract itself.
  - `translator()` runs the `.partial` reset, the build, the swap and the key write inside it.
- `self.env` gains `NUGET_PACKAGES`.
- A live restore of both projects into a temporary `NX2A_HOME` passed the check.
- `lock.take(..., wait=True)` says once whom it waits for and retries every second. Both OSes use the non-blocking call in this loop. Without `wait`, a held lock still stops at once.
- ARCHITECTURE.md now covers:
  - the NuGet check and how to regenerate the pins
  - the tools lock bullet
  - the one-time download of about 50 MB into `nuget/`
- CONCERNS.md `## Closure (Phase 2)` has 58 rows:
  - the 33 bold concerns
  - the 12 Cross-Platform rows
  - the 8 `gui/` bullets
  - the 5 third-party bullets

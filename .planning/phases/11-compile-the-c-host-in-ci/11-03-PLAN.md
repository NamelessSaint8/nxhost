## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-11-09 | Tampering | `TargetRow` reason and path labels | high | mitigate | Porter's `reason` is rendered `Qt.PlainText` and word-wrapped, the path through `firstrun.Elided`, and no `RichText`/`setHtml` is used anywhere in the row — a profile path or reason containing `<`, `&` or a tag cannot become markup (RESEARCH Security V5) |
| T-11-10 | Spoofing | `<Target> · <word>` status text | medium | mitigate | The word comes only from `targets[].status` through one `STATUS_WORD` map, and every row carries a word as well as a colour, so a failure cannot be shown as a bare green glyph |
| T-11-11 | Information disclosure | `Reveal` → `QDesktopServices.openUrl` | low | accept | It opens the parent folder of a path porter reported for this run in the player's own output folder; no new disclosure |
| T-11-12 | Denial of service | result rows | low | accept | At most two rows by construction; the block is never scrollable |
| T-11-SC | Tampering | package installs (npm/pip/cargo) | high | mitigate | No install step exists in this plan: `port_both.jsonl` is generated by the in-repo `tests/fixtures/bridge/record.py`, never downloaded, and `gui/app.py` uses the PySide6 already declared. Any install added here later must pass the legitimacy audit table before landing |
